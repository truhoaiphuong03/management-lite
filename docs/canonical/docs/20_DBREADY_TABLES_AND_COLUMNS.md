# DB-READY — Column contracts (design, NOT executable DDL)
Version 0.1.0-doc.5. PostgreSQL schema `public`. Types: uuid, timestamptz, date, bigint, integer, boolean, text, jsonb; UTC instants; workspace local business dates. `id uuid PK` and `workspace_id uuid NOT NULL` on every tenant-owned row unless noted. `created_at timestamptz NOT NULL` and immutable actor metadata on events; `version integer NOT NULL DEFAULT 1 CHECK(version>0)` on mutable aggregates. `UNIQUE(workspace_id,id)` for every tenant parent referenced by tenant FK. Every tenant FK is composite and ON DELETE RESTRICT/NO ACTION. Default status values only for documented states. No hard deletes of business/history rows.

## Foundation / identity
- workspaces: id PK, name text not null, timezone text not null default 'Asia/Ho_Chi_Minh' (validate IANA at application boundary), status active/suspended, created_at.
- users: id PK, username_normalized text unique not null, email_normalized text unique not null, status pending_activation/active/suspended, version, created_at. Global identity; no tenant data in user record.
- user_credentials: user_id uuid PK FK users, password_hash text not null, credential_version integer >0, password_changed_at timestamptz; never plaintext.
- workspace_memberships: id, workspace_id FK workspaces, user_id FK users, role owner/staff, status invited/active/suspended, version, UNIQUE(workspace_id,user_id), UNIQUE(workspace_id,id).
- employees: id, workspace_id, user_id nullable until invitation linkage, employee_code text not null, full_name text not null, employment_status invited/active/suspended/archived, is_payroll_eligible boolean not null default true, version, UNIQUE(workspace_id,employee_code), UNIQUE(workspace_id,user_id) WHERE user_id IS NOT NULL; composite FK (workspace_id,user_id) -> workspace_memberships(workspace_id,user_id) DEFERRABLE if activation creation ordering requires; Owner membership => eligibility false enforced transactionally and audited (cross-table invariant).
- job_positions: id, workspace_id, code content_creator/video_editor, name, is_active, UNIQUE(workspace_id,code).
- employee_positions: id, workspace_id, employee_id, position_id, is_primary boolean, started_on date, ended_on date nullable, CHECK(ended_on>started_on), nonoverlap primary effective ranges; employee may have multiple positions.
- activation_invites: id, workspace_id, user_id, token_hash unique, token_version integer >0, status queued/issued/used/revoked/expired, expires_at, consumed_at, revoked_at, created_at; one current usable invite per workspace/user enforced under lock. Invite state distinct from delivery state.
- auth_sessions: id, workspace_id, user_id, session_token_hash unique, created_at, last_seen_at, idle_expires_at, absolute_expires_at, revoked_at, credential_version_at_issue; active membership check on each privileged action.
- email_outbox: id, workspace_id, invite_id, message_type, status pending/claimed/sent/failed, attempt_count, next_attempt_at, lease_until, provider_message_id nullable, created_at, updated_at; no raw activation token/link in persistent job payload or logs. Secure transient delivery path must be proven before implementation.
- email_delivery_attempts: id, workspace_id, outbox_id, attempt_no, outcome, provider_message_id nullable, attempted_at, sanitized_error_code nullable, UNIQUE(workspace_id,outbox_id,attempt_no).
- idempotency_records: id, workspace_id, actor_user_id, operation_key, request_fingerprint, state claimed/completed/failed, response_code nullable, sanitized_response jsonb nullable, created_at, expires_at, UNIQUE(workspace_id,actor_user_id,operation_key).
- audit_events: id, workspace_id, actor_user_id nullable for bootstrap, action, entity_type, entity_id, request_id, metadata_sanitized jsonb, created_at; append-only, no secret/token/password.

## Attendance
- attendance_shifts: id, workspace_id, employee_id, clock_in_at, clock_out_at nullable, run_state working/paused/completed, review_state unreviewed/approved/rejected/needs_review, current_version_id nullable (FK added after versions), version, created_at. `clock_out_at>clock_in_at` when closed. One open shift per employee; closed shift overlap forbidden. Review state separate from run state.
- attendance_breaks: id, workspace_id, shift_id, started_at, ended_at nullable, unpaid boolean not null default true; CHECK(ended_at>started_at) when ended; one open break/shift, nonoverlap.
- attendance_shift_versions: id, workspace_id, shift_id, version_number integer >0, clock_in_at, clock_out_at, breaks_snapshot jsonb, worked_seconds bigint >=0, snapshot_hash text not null, created_by, created_at, reason nullable, UNIQUE(workspace_id,shift_id,version_number); immutable; validated canonical snapshot intervals; version is approved unit.
- attendance_approvals: id, workspace_id, shift_id, shift_version_id, reviewer_user_id, decision approved/rejected, reason nullable, reviewed_at, UNIQUE(workspace_id,shift_version_id); reviewer must not be employee's own user (transactional guard); immutable.
- attendance_adjustments: id, workspace_id, shift_id, from_version_id nullable, to_version_id, actor_user_id, reason text not null, created_at; immutable provenance. Open forgotten shift correction requires separate authorization and cannot silently finalize.

## Payroll
- pay_rates: id, workspace_id, employee_id, hourly_rate_vnd bigint CHECK >=0, effective_from timestamptz, effective_to timestamptz nullable, CHECK(effective_to>effective_from); exclusion no overlapping [) intervals for same employee/workspace.
- payroll_periods: id, workspace_id, starts_on date, ends_on date, timezone_snapshot text, status draft/finalized, calculation_revision integer >0, finalized_at nullable, finalized_by nullable, finalized_snapshot_hash nullable, version; CHECK(ends_on>starts_on); exclusion no overlapping date ranges per workspace.
- payroll_items: id, workspace_id, period_id, employee_id, approved_seconds bigint CHECK >=0, base_pay_vnd bigint CHECK >=0, bonus_vnd bigint CHECK >=0, allowance_vnd bigint CHECK >=0, advance_vnd bigint CHECK >=0, deduction_vnd bigint CHECK >=0, net_amount_vnd bigint, calculation_revision integer, UNIQUE(workspace_id,period_id,employee_id). Negative net amount is a POLICY HOLD: do not finalize affected item without Owner decision.
- payroll_calculation_lines: id, workspace_id, payroll_item_id, approved_shift_version_id, pay_rate_id, segment_start_at, segment_end_at, worked_seconds bigint CHECK >0, hourly_rate_vnd_snapshot bigint CHECK >=0, numerator_vnd_seconds numeric(38,0) CHECK >=0, timezone_snapshot text, UNIQUE(workspace_id,payroll_item_id,approved_shift_version_id,segment_start_at,segment_end_at); [start,end) half-open; exact numerator; immutable after finalize.
- payroll_adjustments: id, workspace_id, payroll_item_id, adjustment_type bonus/allowance/advance/deduction, amount_vnd bigint CHECK >=0, reason text not null, created_by, created_at; pre-finalize adjustments feed snapshot, no direct post-finalize mutation.
- payroll_correction_entries: id, workspace_id, original_payroll_item_id, affected_employee_id, amount_vnd bigint signed CHECK <>0, reason text not null, evidence_reference text nullable, created_by, created_at, posting_period_id nullable, status recorded/voided (void is compensating entry, not delete); immutable ledger. Settlement/disbursement out of V0.1 unless separately approved.

## Reports / Accounts
- daily_reports: id, workspace_id, employee_id, report_date date, status draft/submitted, current_revision integer >0, version, created_at, submitted_at nullable, UNIQUE(workspace_id,employee_id,report_date).
- daily_report_entries: id, workspace_id, report_id, channel_id nullable, work_type text, reported_count integer CHECK >=0, notes text nullable; optional channel FK only after channels exist.
- daily_report_revisions: id, workspace_id, report_id, revision_number integer >0, snapshot jsonb, edited_by, edited_at, UNIQUE(workspace_id,report_id,revision_number); immutable.
- managed_accounts: id, workspace_id, platform, platform_account_id nullable, username nullable, status active/archived, notes nullable, version, created_at; Owner-only.
- account_secrets: id, workspace_id, account_id, secret_type, ciphertext bytea, nonce bytea, auth_tag bytea (if crypto library returns separately), key_version text, encryption_schema_version integer, created_at, updated_at, UNIQUE(workspace_id,account_id,secret_type); crypto key outside DB; AAD binds workspace/account/type/schema.
- contact_points: id, workspace_id, type, normalized_value, display_value, UNIQUE(workspace_id,type,normalized_value).
- account_contact_links: id, workspace_id, account_id, contact_point_id, relationship_type, UNIQUE(workspace_id,account_id,contact_point_id,relationship_type).
- account_relationships: id, workspace_id, source_account_id, target_account_id, relationship_type, CHECK(source_account_id<>target_account_id), UNIQUE(workspace_id,source_account_id,target_account_id,relationship_type).
- secret_access_events: id, workspace_id, actor_user_id, account_id, action, created_at, request_id; append-only; no secret value.
